* Automated Architecture Search for Lightweight AI

Larger AI is typically better at what it does. However, models can't be arbitrarily large. The bigger the model, the higher the costs in terms of hardware, energy and money.

Pareto-based, multi-objective optimisation can discover efficient trade-offs between model accuracy and computational cost for lightweight AI.

This project shows a custom framework for evolving CNN architectures using multi-objective neuroevolution, where populations of neural networks change over generations pushed by some evolutionary pressure.

* Online User Experience Analyser

Understanding user experience is key to any successful product or service - and what better way to know if someone enjoys something than asking?

This web application interprets textual sentiment as a proxy for how users feel about the web page itself.

A transformer-based NLP model interprets user feedback and stores sentiment metrics in a lightweight database backend.
